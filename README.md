# 📌 ***Тест-кейсы для проверки страницы  https://www.jetbrains.com/space***  

**Предусловия:**  
- Открыта страница входа (https://www.jetbrains.com/space)

### **1. Проверка перехода на главную страницу по клику на логотип**
**Описание:** Проверяем, что при нажатии на логотип происходит переход на главную страницу JetBrains.  
**Метод:** `buttonCheck()`
 
 **Шаги:**
  1. Нажать на кнопку **"Принять всё"** в всплывшем окне Настройки файлов куки
  2. Нажать на логотип **"JetBrains"**

**Ожидаемый результат:**
- URL текущей страницы должен быть `https://www.jetbrains.com/`  

### **2. Проверка отображения кнопки "Developer Tools"**
 **Описание:** Убеждаемся, что кнопка "Developer Tools" отображается в верхнем меню.  
 **Метод:** `displayedDevToolsButtonCheck()`  
 
 **Шаги:**
  1. Нажать на кнопку **"Принять всё"** в всплывшем окне Настройки файлов куки

 **Ожидаемый результат:** 
 - Кнопка должна быть видимой.

### 3. **Проверка открытия меню при нажатии "Developer Tools"**

  2. Нажать на кнопку **Developer Tools"**

### 4. **Проверка изменения цвета кнопки "Team Tools" при наведении на неё фокуса**
 **Описание:** Проверяем, что при наведении фокуса на кнопку Team Tools её текст становится белого цвета (Отключается прозрачность).  
 **Метод:** `onFocusColorTeamToolButtonCheck()`  
 
 **Шаги:**

 **Ожидаемый результат:**
 - Цвет текста кнопки должен стать белым.

### 6. **Проверка изменения страны на "France"**

 **Шаги:**
  1. Нажать на кнопку **"Принять всё"** в всплывшем окне Настройки файлов куки

### **13. Проверка ошибки при вводе невалидного email**
**Описание:** Вводим невалидные email и проверяем текст ошибки.  
**Метод:** `errorTextAfterNotValidEmailCheck()`  
  
 
 **Шаги:**
  1. Нажать на кнопку **"Принять всё"** в всплывшем окне Настройки файлов куки
  2. Нажать на кнопку **"Sign In"**
  3. Нажать на кнопку **"… or use another email account"**
  4. Ввести невалидный **"email"** `test`, `test@`, `test@test`
  5. Нажать **"Continue with this email""**

 **Ожидаемый результат:**
 - Должно отображаться сообщение **"Please enter a valid email address"**.

 **Шаги:**

### 20. Проверка отправки отзыва в немецкой версии сайта
 **Описание:** Проверяем, что после заполнения формы "Feedback" в немецкой версии сайта отображается сообщение подтверждения.  
 **Метод:** `feedAnswerTextCheck()`  
 
 **Шаги:**
  1. Нажать на кнопку **"Принять всё"** в всплывшем окне Настройки файлов куки
  2. Выбрать немецкий язык в  языковом меню
  3. Нажать на закладке **"Feedback"**
  4. Выставить 5 звезд
  5. Нажать на кнопку **"Weiter"**
  6. Ввести текст отзыва (например, 'Gute Website!')
  7. Нажать на кнопку **"Weiter"**  
  
 **Ожидаемый результат:** 
 - Должно появиться сообщение **"Großartig! Vielen Dank für Ihr Feedback!"**
